How "resolution type" is worked out: each Open Comment is read against a set of keyword rules — “outstanding / required” documentation reads as Chase paperwork, “pending / to determine suitability” reads as Info / review needed, “to be installed / missing / cut” reads as Physical work, and nameplate or CE-marking mismatches read as Compliance. It's a heuristic reading of the wording AVS logged, not a judgment call by AVS or Anthropic — check the underlying comment before treating a categorisation as final.

Uploads and tracking: uploading a workbook replaces the data below and is saved only in this browser, on this device — nothing is sent anywhere. Ticking an item as resolved is tracked the same way, matched to that exact comment line, so re-uploading a fresh export keeps your progress as long as the wording hasn't changed.
