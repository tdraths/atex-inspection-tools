ATEX Tool Kit

Inspection Tools

Three tools built to close specific gaps in day-to-day ATEX inspection work - each one replacing a manual Excel or export-and-email process with something live and explorable. Click any tool below to try it with anonymised sample data.

← Back to tdraths.github.io

All three run entirely in your browser - nothing is sent anywhere. Sample data loads by default; each tool also accepts a real workbook upload if you want to see it populate from your own data (nothing you upload leaves your machine either).
